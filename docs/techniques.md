## 1. 构图脑洞

画面怎么「装」东西：用一个意想不到的结构来组织画面。


### 轮廓里长出一个世界

画一个清楚的大轮廓（侧脸、莲花、门、头发），把一整个小世界装进去或长在上面，外面大量留白。轮廓负责「一眼认出」，里面负责「越看越多」。

**关键写法**

- 点名轮廓，并要求它占画面中心、清晰可辨：a clear, recognizable contour occupying the center
- 说明世界是「长」出来的，不是塞进去的：a complete world grows within / upon the contour
- 反套路一句：别默认用瓶子、沙漏、玻璃罩，让模型自己挑最有象征意义的轮廓
- 配大留白、纸纹、薄雾，收藏级海报感：large negative space, paper grain, soft fog

### 用疏密让形象「浮现」

不直接画主体，而是用大量小元素（笔记、树叶、鸟、文字）铺满画面，只在主体的位置变密或改变排列，让形象自己浮出来。看的人会有一个「啊，原来是张脸」的瞬间。

**关键写法**

- 先说铺满的材料：masses of handwritten notes / leaves / birds covering the surface
- 再说规则：density concentrates where the face is, so the face emerges from the chaos
- 明确禁止写实画法：the face is not drawn realistically, no realistic portrait
- 限定颜色（黑白加一点红）防止画面变花

### 尺度错位

把东西放到不该有的大小：头发里有微缩城市、拿铁杯上站着小人、从原子一路放大到地球。大小一错，普通题材就变成奇观。

**关键写法**

- 写清两边的尺度：tiny people walking between the hair strands, extremely small but realistic proportions
- 用微距摄影的语言加真实感：macro photography, 85mm, shallow depth of field
- 科普用法：一层层圆框从最小到最大排开（zoom-sequence infographic）

### 一条主线当骨架

信息很多时，先给画面一条贯穿全画的线（水墨 S 形笔触、红绸、长卷），再让所有元素沿着这条线排开。画面立刻有了方向和节奏，不会乱。

**关键写法**

- a bold ink S-curve sweeping across the canvas, forming the visual backbone
- 说明元素如何排在线上：landmarks arranged in staggered sequence along the curve
- 搭配非线性透视、冷色为主暖色点缀

### 套娃与分身

## 2. 跨界混搭

让本来不该在一起的东西出现在一起，冲突本身就是看点。


### 两个世界撞在一起

故意让不同规则的世界碰面：二次元角色走进真实街道，橡皮鸭当真人电影主角，写实的人从漫画格子里冲出来，蒙娜丽莎喝可乐。

**关键写法**

- 明确保留哪一边的风格：keep the flat 2D cel style while the environment is photorealistic
- 强调对比：full-color realistic figure vs monochrome manga environment
- 给出冲突的具体动作（冲破分镜框、一条腿迈进现实）

### 伪装成现实里的载体

不说「画一张图」，而说「这是一张 × ×」：老报纸头版、手机截图、纪念邮票、处方笺、课本内页、直播截图。把这个载体该有的零件全部点名，就会像真的。

**关键写法**

- 先定载体，再列它的全部惯例零件：报头、日期、期号、分栏小字、折痕、油墨瑕疵
- 截图类要写状态栏、导航栏、互动数字、对话框
- 质感一句：paper texture, grain, ink defects, slightly worn

## 3. 专业语言

用行内人的词代替「好看」「高级」，模型才知道你要什么。


### 「A 遇上 B 遇上 C」

用具体的画家、流派、出版物来定风格，比写「高级感」有效得多。例如把食物剖开当博物馆标本，风格写成奥杜邦博物画 × 卡拉瓦乔的光 × 科学摄影。

**关键写法**

- Audubon naturalist illustration meets Caravaggio lighting meets scientific photography
- 再用反面收窄：Realistic style, not diagram, not cartoon
- 指定要像哪种出版物：国家博物馆展板、老百科全书、Apple 发布会页

### 拆开给人看

爆炸图、剖面图、结构拆解：把产品、食物、古建筑拆开，每个部件配引线标注。又有信息量又好看，特别适合科普和产品介绍。

**关键写法**

- exploded assembly drawing / cross-section / structural breakdown
- 标注贴着部件走，不要飘着：labels hug the structural edges, never floating
- 每条标注固定格式：名称 + 数据 + 一句大白话

### 只留一个颜色

整张图低饱和或黑白，只让一个地方是鲜艳色：远处的红裙小人、笔记上的红墨水。视线被强行拉过去，画面马上有设计感。

- 先限定主色：monochrome / low-saturation palette，再说唯一的点缀色
- 点缀物越小越有效

### 文字长在场景里

字不是贴上去的标题，而是场景的一部分：刷在大桥路面上随透视变小，城市名的字母里塞满地标，书法字本身就是画。

**关键写法**

- painted directly onto the surface, conforming to its curvature, surface-integrated rather than floating
- extreme perspective, foreshortening toward the vanishing point
- 城市字海报：the city name itself becomes the composition
- 中文字一定写出要显示的原字，并加「不要乱码」

## 4. 工作方法

不是某种风格，而是让出图更稳、更可控的做法。


### 宫格锁住一致性

同一个人、同一个角色放进 N 宫格，只改一个变量（发型、动作、场景）。既是好看的成品，也是检验角色一致性的办法，做视频关键帧前很有用。

**关键写法**

- a 12-panel grid (3×4), numbered, showing the SAME person
- 写死唯一变化项：THE ONLY THING THAT CHANGES IS THE HAIR
- 写身份锚点：face must stay identical to the reference

### 让 AI 先想、再画

不给画面细节，只给一个开放问题，让模型自己推理：「根据你对我的了解画出你认识的我」「2020 年最重要的事件」「看这张海报，想象它的预告片」。也可以先让它写 800 字剧情，再按剧情画四格漫画。

**关键写法**

- 一步式：Look at this poster, imagine it yourself, and create a trailer-style key frame
- 两步式：先要文字方案，确认后说「画吧」
- 适合找灵感，不适合要精确结果

### 反向拆解成参数

拿一张喜欢的参考图，先让模型把它的调色、光线、每个颜色拆成一份参数清单（JSON），再用这份清单生成新图。以后每张都挂同一份参数，风格就不会漂。

**关键写法**

- Analyze this photo and give me a detailed JSON prompt that recreates it; break down the color grading
- Use that JSON as the reference for lighting and color; the model handles the character
- 很多高手的提示词本身就写成 JSON（身份锁、构图、光线分字段），方便改一项不动其他
